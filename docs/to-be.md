# AS-IS проблемалары және TO-BE шешімі

## AS-IS проблемалары
- Тапсырысты қолмен өңдеу: көп уақыт алады, адам қателігі болуы мүмкін.
- Тапсырыс жеткізетін көлікте сүт бұзылып кетуі мүмкін.
- Сапаны тексеру процесі баяу, нәтиже бөлек тіркеледі.

## TO-BE кестесі
| Функция | TO-BE шешімі |
|---|---|
| Тапсырысты тіркеу | Автоматты |
| Қоймадағы қалдықты бақылау | Автоматты |
| Өнімнің жарамдылық мерзімі | Автоматты бақылау |
| Сапа нәтижесін сақтау | Жүйеде сақталады |
| Тапсырыс мәртебесі | Автоматты жаңартылады |
| Логистика | Жүйе жеткізу маршрутын ұсынады |
| Есеп беру | Автоматты түрде қалыптасады |
| Әкімшілік бақылау | Бір жүйеден басқарылады |

## TO-BE өзгерістері
- Сапа бақылаушысы рөлі жойылды, сапа тексерісі автоматты.
- Клиент рөлі қосылды: тапсырыс беру, статус қарау.
- Оффлайн жеткізу режимі, таулы аймақ, SMS хабарлама қосылды.
